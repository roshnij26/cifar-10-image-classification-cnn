# cifar-10-image-classification-cnn
Deep Learning image classification model using Convolutional Neural Network (CNN) on the CIFAR-10 dataset to classify images into 10 object categories. 

## Dataset
- Source: Kaggle - CIFAR-10 Dataset
- Shape: 60,000 images
- Number of Classes: 10

## Technologies Used
- Python
- pandas
- NumPy
- scikit-learn
- PyTorch

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis(EDA)
3. Feature Engineering
4. Data Preprocessing
5. Model Building
6. Model Training
7. Evaluation

## Results
- Accuracy:  74.71
